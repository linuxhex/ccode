## 🚀 部署就绪

### 系统要求

- Rust 1.75+
- ZeroMQ 4.3+
- Tokio runtime

### 启动步骤

1. **编译**
   ```bash
   cargo build --release
   ```

2. **配置**
   ```bash
   # 创建 ccode.toml
   cp docs/examples/ccode.toml ccode.toml
   ```

3. **启动 Kernel**
   ```bash
   ./target/release/ccode-kernel
   ```

4. **启动 Agent**
   ```bash
   ./target/release/ccode-agent
   ```

# @ccode-official/ccode-win32-x64

Platform-specific binary for [`@ccode-official/ccode`](https://www.npmjs.com/package/@ccode-official/ccode) on win32-x64.

Do not install this package directly. Install the main package instead:

```sh
npm install -g @ccode-official/ccode
```

The main package will automatically pull the correct binary for your platform via `optionalDependencies`.
